# Pocket Fridge

> Your unopened notifications go into a phone-sized fridge where they start tasting wrong.

A mobile app that imports notifications into sealed refrigerator drawers based on sender, app, or mood. If you leave them too long, they curdle, smell, or expire with a sourness score. The fridge refuses to let you eat the best one first unless you accept the weird taste report.

## Features
- Capture notifications into refrigerated drawers for work, friends, apps, and doom
- Track curdling timers that change color, weight, and smell score over time
- Serve a taste-test digest that rates which notifications are still edible or ruined
- Let one spoiled item infect neighboring drawers if ignored for more than a set number of hours

## Stack
- React Native
- SQLite
- React Native Push
- Reanimated

## Getting started
```
npm install; npm start; run npm run ios or npm run android
```
